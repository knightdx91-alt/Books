# Book One cover art — read before touching the wrap

**The published Book One cover is the PENDANT** — a dark faceted stone on a fine
chain with an ember inside it:

    hazel-academy-front-cover-PUBLISHED-pendant.png

It is verified byte-identical to `ebook-cover-book1-hazel-academy.jpg` and to the
live site's `assets/images/hazel-academy-cover.jpg`, and it is what the Amazon
listing (B0H6R5C39M) shows. It is also what the accepted r1–r3 print wraps used.

`hazel-academy-front-cover-UNUSED-keyhole.png` is a DIFFERENT, unpublished concept
(a keyhole with a glow). It used to be named plain `hazel-academy-front-cover.png`,
which read like the canonical file and was not — that name caused the r18 wrap to be
built with the wrong cover on 2026-09-01. Renamed so the trap can't be stepped in
again. Do not ship it without an explicit decision from the author.

`-print` variants are Lanczos upscales generated by `tools/cover_art_to_print_res.py`
so the art clears 300 dpi on the print panel; regenerate rather than editing.
